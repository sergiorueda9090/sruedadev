# PROMPT MAESTRO — SITIO WEB CORPORATIVO PREMIUM
## Cooperativa Santandereana de Transportadores Limitada | Bucaramanga, Colombia

Actúa como un equipo multidisciplinario de alto nivel integrado por:

- Un Senior Frontend Developer con más de 10 años de experiencia.
- Un diseñador UI/UX especializado en páginas corporativas de transporte y logística.
- Un director de arte digital especializado en branding empresarial.
- Un especialista en SEO técnico y posicionamiento local.
- Un experto en conversión digital y experiencia de usuario.
- Un especialista en accesibilidad, rendimiento y diseño responsive.

Tu misión es diseñar y desarrollar una página web corporativa excepcional para la **Cooperativa Santandereana de Transportadores Limitada**, una empresa cuyo nombre identifica una organización vinculada al sector del transporte en Bucaramanga, Santander, Colombia.

El resultado debe transmitir solidez, seguridad, experiencia, profesionalismo y capacidad operativa.

IMPORTANTE: no inventes información real de la cooperativa. Los servicios específicos, la historia, los años de experiencia, la flota, los permisos, las certificaciones, los teléfonos, los correos, los horarios y las cifras empresariales deben verificarse antes de publicarse. Cuando un dato no esté confirmado, utiliza contenido provisional claramente identificado y centraliza esos datos para facilitar su actualización.

---

# 1. OBJETIVO DEL PROYECTO

Crear una página web corporativa moderna, elegante y estratégica que permita:

1. Presentar la empresa de manera profesional.
2. Comunicar claramente sus actividades y servicios confirmados.
3. Generar confianza entre clientes, aliados y empresas interesadas.
4. Facilitar el contacto comercial.
5. Permitir solicitudes de información y cotizaciones cuando corresponda a los servicios reales.
6. Mostrar fotografías de calidad relacionadas con el transporte.
7. Mejorar la presencia digital de la cooperativa en Google.
8. Funcionar correctamente en celulares, tablets y computadores.
9. Proporcionar una estructura preparada para futuras integraciones, como WhatsApp, formularios conectados a un backend o herramientas de analítica.

No construyas una web genérica. Desarrolla una experiencia corporativa con identidad visual propia, jerarquía visual impecable y una narrativa comercial coherente.

# 2. TECNOLOGÍAS OBLIGATORIAS

Utiliza exclusivamente las siguientes tecnologías para la implementación del frontend:

- HTML5 semántico.
- CSS3 moderno.
- Bootstrap 5.
- JavaScript vanilla ES6+.
- AOS (Animate On Scroll) para animaciones de entrada, cuando aporte valor.
- Bootstrap Icons para iconografía.
- Google Fonts con una familia sans-serif profesional, como Inter u Open Sans.

No utilices React, Vue, Angular, Tailwind CSS, TypeScript ni frameworks adicionales de frontend.

Puedes utilizar Google Fonts, AOS y Bootstrap Icons mediante sus recursos oficiales, con versiones fijadas cuando corresponda.

La página debe poder ejecutarse localmente mediante un servidor estático sencillo.

# 3. DIRECCIÓN CREATIVA Y ESTILO VISUAL

Desarrolla una estética corporativa premium inspirada en las mejores páginas de empresas de transporte, movilidad, logística y servicios empresariales.

## Personalidad visual

La interfaz debe comunicar:

- Confianza.
- Seguridad.
- Responsabilidad.
- Organización.
- Experiencia.
- Cobertura operativa, únicamente si se confirma.
- Compromiso con el cliente.
- Profesionalismo.

## Paleta cromática propuesta

Utiliza esta paleta inicial y adáptala si se encuentra un logotipo o identidad visual oficial:

- Azul marino: #102A43.
- Azul corporativo: #1769AA.
- Azul claro: #EAF3FA.
- Blanco: #FFFFFF.
- Gris de fondo: #F5F7FA.
- Gris de texto: #526171.
- Gris oscuro: #243447.
- Color de acento: #F2A900, usado con moderación.

El azul debe ser el color principal. El amarillo puede utilizarse en botones, indicadores o pequeños detalles para aportar energía visual.

Evita utilizar demasiados colores, gradientes exagerados, sombras excesivas, efectos luminosos o tarjetas repetitivas.

## Tipografía

Utiliza Inter u Open Sans.

Establece una jerarquía clara entre títulos, subtítulos, texto descriptivo, etiquetas y botones.

Los títulos deben ser firmes y legibles. Los párrafos deben tener una longitud de línea cómoda y un interlineado adecuado.

## Composición

Combina:

- Grandes espacios en blanco.
- Secciones de ancho completo.
- Contenedores con dimensiones consistentes.
- Fotografías corporativas amplias.
- Composiciones asimétricas controladas.
- Tarjetas informativas selectivas.
- Iconos sencillos.
- Líneas divisorias discretas.
- Microinteracciones suaves.

La web debe sentirse diseñada por una agencia digital especializada en empresas de transporte.

# 5. DISEÑO DETALLADO DE LA PÁGINA PRINCIPAL

## SECCIÓN 1. BARRA SUPERIOR INFORMATIVA

Diseña una franja superior delgada y elegante.

Puede contener, si la información está confirmada:

- Ubicación en Bucaramanga, Santander.
- Teléfono corporativo.
- Correo electrónico.
- Horario de atención.
- Enlace de contacto.

Utiliza iconos pequeños y una composición limpia.

En dispositivos móviles, oculta los elementos secundarios que dificulten la navegación y conserva el acceso al contacto.

No inventes números telefónicos ni direcciones.

## SECCIÓN 2. HEADER Y NAVEGACIÓN PRINCIPAL

Diseña un encabezado corporativo profesional.

A la izquierda:
- Logotipo oficial, si está disponible.
- Nombre de la cooperativa como alternativa provisional.

A la derecha:
- Inicio.
- Nosotros.
- Servicios.
- Operación o cobertura, únicamente si aplica.
- Seguridad y compromiso.
- Contacto.

Incluye un botón destacado: "Solicitar información".

Características:

- Header responsive.
- Menú móvil funcional.
- Estados hover discretos.
- Contraste adecuado.
- Transiciones suaves.
- Header sticky opcional, solo si mejora la experiencia.

No inventes un logotipo oficial ni presentes una identidad gráfica creada como si fuera la original.

## SECCIÓN 3. HERO PRINCIPAL DE ALTO IMPACTO

Esta sección debe captar la atención durante los primeros segundos.

Utiliza una fotografía panorámica profesional relacionada con el tipo de transporte que realmente realiza la cooperativa.

Si la actividad exacta no está confirmada, utiliza temporalmente una imagen de transporte terrestre con una indicación interna de que debe sustituirse después de verificar la actividad empresarial.

Composición recomendada:

- Fotografía amplia como fondo o elemento dominante.
- Capa de contraste sutil para facilitar la lectura.
- Titular principal alineado a la izquierda.
- Subtítulo descriptivo.
- Dos botones de acción.

Titular provisional:

"Experiencia y compromiso al servicio del transporte"

Subtítulo provisional:

"Conoce nuestra organización, nuestros servicios y las soluciones de transporte que podemos ofrecerte."

Estos textos deben adaptarse a la actividad y propuesta de valor reales de la cooperativa antes de publicar.

Botones:

- "Conocer nuestros servicios".
- "Contactar con la cooperativa".

El primer botón debe desplazarse a la sección de servicios. El segundo debe llevar al formulario o a los datos de contacto verificados.

No afirmes que la empresa es líder, tiene cobertura nacional, opera una flota determinada o posee décadas de experiencia sin documentación que lo respalde.

## SECCIÓN 4. PRESENTACIÓN CORPORATIVA

Título sugerido:

"Una cooperativa comprometida con el transporte"

Desarrolla una sección editorial que explique quién es la organización y qué hace.

Diseño:

- Columna de texto.
- Fotografía secundaria.
- Etiqueta corporativa.
- Título de alto impacto.
- Párrafos breves.
- Enlace para ampliar información.

El contenido debe construirse con información empresarial verificada.

Si no se dispone de una descripción oficial, utiliza un texto provisional como:

"Estamos preparando una presentación corporativa de la Cooperativa Santandereana de Transportadores Limitada. Próximamente podrás consultar aquí información confirmada sobre su historia, actividad, organización y servicios."

No publiques ese texto provisional como contenido final.

## SECCIÓN 5. SERVICIOS DE TRANSPORTE

Esta sección es fundamental, pero debe reflejar únicamente los servicios que la empresa presta realmente.

Antes de desarrollarla, comprueba si la cooperativa se dedica a:

- Transporte de pasajeros.
- Transporte especial.
- Transporte de carga.
- Transporte empresarial.
- Transporte turístico.
- Logística.
- Otros servicios especializados.

No asumas que ofrece todas estas modalidades.

Cuando los servicios estén confirmados, crea una tarjeta visual para cada uno.

Cada tarjeta puede incluir:

- Fotografía o icono.
- Nombre del servicio.
- Descripción breve.
- Beneficio para el cliente.
- Enlace "Solicitar información".

Evita que todas las tarjetas sean visualmente idénticas. Combina una composición principal destacada con tarjetas secundarias.

Si no hay información verificada, crea una sección temporal de servicios pendientes de validación y no publiques modalidades especulativas.

## SECCIÓN 6. PROPUESTA DE VALOR

Crea una sección para explicar los atributos diferenciales confirmados de la cooperativa.

Posibles temas, únicamente si están respaldados por información real:

- Atención al cliente.
- Responsabilidad operativa.
- Seguridad.
- Organización.
- Experiencia del equipo.
- Cumplimiento normativo.
- Gestión eficiente.

Utiliza cuatro bloques visuales como máximo.

Cada bloque debe contener:

- Icono.
- Título breve.
- Descripción concreta.

No utilices frases vacías como "somos los mejores" o "calidad garantizada" sin evidencia.

## SECCIÓN 7. OPERACIÓN, COBERTURA O INFRAESTRUCTURA

Incluye esta sección solo cuando existan datos confirmados.

Según la actividad de la cooperativa, puede presentar:

- Municipios atendidos.
- Rutas autorizadas.
- Instalaciones.
- Vehículos.
- Centros operativos.
- Modalidades de servicio.

Si se publican cifras, deben tener una fuente verificable y una fecha de actualización.

No inventes mapas, rutas, ubicaciones operativas ni estadísticas.

Si no se dispone de esta información, reemplaza la sección por una composición visual sobre la forma de trabajo de la empresa, sin afirmar capacidades que no estén verificadas.

## SECCIÓN 8. SEGURIDAD Y RESPONSABILIDAD

Diseña una sección que inspire confianza sin realizar afirmaciones legales no verificadas.

Puede contener información confirmada sobre:

- Protocolos operativos.
- Gestión de riesgos.
- Mantenimiento.
- Formación del personal.
- Seguros.
- Cumplimiento normativo.

No utilices sellos de certificación ficticios, insignias oficiales inventadas ni imágenes que sugieran acreditaciones inexistentes.

Si la información no está disponible, crea una sección institucional sobria que invite a consultar las políticas y condiciones directamente con la cooperativa.

## SECCIÓN 9. INDICADORES EMPRESARIALES

Incluye indicadores numéricos únicamente si existen datos reales, actuales y verificables.

Ejemplos de indicadores posibles:

- Años de operación.
- Número de asociados.
- Vehículos vinculados.
- Municipios atendidos.
- Clientes empresariales.

No utilices contadores animados con cifras inventadas.

Si no hay datos confirmados, omite esta sección hasta que la empresa facilite la información.

## SECCIÓN 10. LLAMADA A LA ACCIÓN

Diseña una sección de alto contraste que invite al usuario a establecer contacto.

Título sugerido:

"Conversemos sobre tus necesidades de transporte"

Texto:

"Contáctanos para conocer más sobre nuestra organización y consultar la disponibilidad de los servicios que ofrecemos."

Botones:

- "Contactar ahora".
- "Consultar servicios".

Los botones deben dirigir a destinos reales y funcionales.

## SECCIÓN 11. FORMULARIO DE CONTACTO

Diseña un formulario visualmente impecable con los siguientes campos:

- Nombre completo.
- Empresa, opcional.
- Correo electrónico.
- Teléfono, opcional.
- Tipo de consulta.
- Mensaje.
- Aceptación de la política de tratamiento de datos personales, cuando corresponda.

Utiliza validaciones de HTML y JavaScript.

Requisitos:

- Etiquetas visibles.
- Mensajes de error comprensibles.
- Indicadores de campos obligatorios.
- Estados de carga y éxito cuando exista integración real.
- Protección frente a envíos duplicados.
- Diseño responsive.

IMPORTANTE: JavaScript por sí solo no envía correos ni almacena solicitudes de manera persistente.

Si no existe backend, crea el formulario como componente visual funcional con validación local y deja claramente documentado que el envío requiere una integración posterior.

No muestres un mensaje de "solicitud enviada" si el mensaje realmente no se ha transmitido.

## SECCIÓN 12. FOOTER CORPORATIVO

Crea un pie de página elegante y completo.

Incluye:

- Nombre empresarial.
- Logotipo autorizado, si existe.
- Resumen corporativo.
- Enlaces de navegación.
- Datos de contacto verificados.
- Dirección confirmada.
- Redes sociales oficiales, si existen.
- Política de privacidad.
- Tratamiento de datos personales.
- Aviso de derechos de autor.

No inventes perfiles sociales, correos, teléfonos, direcciones ni enlaces legales.

# 6. FOTOGRAFÍA Y DIRECCIÓN DE ARTE

Utiliza imágenes de calidad profesional.

Prioriza:

- Vehículos reales de la modalidad de transporte correspondiente.
- Fotografías corporativas.
- Escenas operativas naturales.
- Paisajes y carreteras pertinentes.
- Personal y equipos de trabajo, cuando existan fotografías autorizadas.

Evita:

- Fotografías de baja resolución.
- Imágenes excesivamente artificiales.
- Collages desordenados.
- Fotografías repetidas en varias secciones.
- Vehículos que no correspondan a la actividad real.
- Logotipos de otras empresas presentados como propios.

Utiliza imágenes optimizadas, atributos `alt` descriptivos y formatos modernos cuando estén disponibles.

Si no existen fotografías oficiales, utiliza imágenes provisionales de bancos con licencia apropiada y documenta qué recursos deben reemplazarse.

# 7. ANIMACIONES E INTERACCIONES

Utiliza AOS para animaciones sutiles de entrada.

Aplica efectos a:

- Títulos.
- Bloques de contenido.
- Fotografías.
- Tarjetas de servicios.
- Llamadas a la acción.

Utiliza transiciones CSS para botones y enlaces.

Las animaciones deben mejorar la experiencia, no distraer.

Respeta la preferencia del usuario por movimiento reducido mediante `prefers-reduced-motion`.

No utilices efectos de parallax pesados ni animaciones que perjudiquen el rendimiento en dispositivos móviles.

# 8. EXPERIENCIA RESPONSIVE

Diseña primero una estructura adaptable y comprueba las siguientes resoluciones:

- 360 × 800.
- 390 × 844.
- 768 × 1024.
- 1366 × 768.
- 1920 × 1080.

Verifica:

- Menú móvil.
- Escalado de titulares.
- Recorte de imágenes.
- Espaciado entre secciones.
- Legibilidad de textos.
- Botones accesibles.
- Formularios.
- Footer.
- Ausencia de desbordamiento horizontal.

No basta con que la página se reduzca de tamaño: debe conservar una composición bien diseñada en cada dispositivo.

# 9. SEO TÉCNICO Y SEO LOCAL

Implementa:

- Etiqueta `title` descriptiva.
- Meta descripción.
- Etiqueta canonical solo cuando la URL definitiva esté definida.
- Jerarquía correcta de encabezados.
- Etiquetas semánticas.
- Open Graph.
- Favicons cuando existan recursos autorizados.
- Enlaces internos funcionales.
- Atributos `alt`.
- URLs y metadatos coherentes.

Utiliza como orientación una frase clave relacionada con el nombre empresarial y Bucaramanga, sin repetirla artificialmente.

No añadas direcciones, coordenadas, teléfonos ni datos estructurados empresariales sin verificarlos.

Si se implementa Schema.org, utiliza el tipo de organización que corresponda realmente a la empresa. No marques servicios o ubicaciones que no estén confirmados.

Objetivos:

- Código limpio.
- HTML semántico.
- CSS organizado.
- JavaScript modular cuando sea conveniente.
- Imágenes optimizadas.
- Carga diferida de imágenes fuera del primer viewport.

- Navegación mediante teclado.
- Estados de foco visibles.
- Formularios accesibles.
- Ausencia de errores en consola.

# 11. FUNCIONALIDADES MÍNIMAS

Comprueba que:

1. El menú funciona.
2. Los enlaces de navegación apuntan a secciones existentes.
3. Los botones de contacto tienen un destino válido.
4. Las animaciones se ejecutan correctamente.
5. El formulario valida sus campos.
6. Las imágenes se cargan.
7. La página funciona en diferentes tamaños de pantalla.
8. No existen errores evitables en la consola.
9. Los enlaces externos funcionan y no conducen a destinos ficticios.

# 13. RESULTADO FINAL ESPERADO

Desarrolla una web corporativa con calidad visual de agencia profesional, lista para ejecutarse localmente y preparada para incorporar información empresarial verificada.

La web debe tener una identidad visual coherente, un hero impactante, servicios claramente presentados, navegación intuitiva, fotografías profesionales, contenido institucional bien jerarquizado y llamadas a la acción estratégicas.

Al finalizar:

1. Ejecuta las pruebas disponibles.
2. Corrige los errores detectados.
3. Resume los archivos creados y modificados.
4. Indica cómo ejecutar el proyecto.

6. Identifica las imágenes provisionales que deben sustituirse.
7. Separa claramente lo que está implementado de lo que requiere backend o validación empresarial.

Comienza analizando la estructura del proyecto y luego implementa la solución completa. No te limites a proponer ideas o entregar fragmentos de código: trabaja directamente sobre los archivos del proyecto.
