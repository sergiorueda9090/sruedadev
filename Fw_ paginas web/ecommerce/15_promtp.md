# PROMPT 14 — CONTACTO Y ATENCIÓN AL CLIENTE

Construye una página de contacto profesional y clara.

## CONTENIDO

- Titular: “Estamos aquí para ayudarte”.
- Descripción breve.
- Formulario de contacto.
- Motivo de consulta.
- Nombre.
- Correo.
- Número de pedido opcional.
- Mensaje.
- Información comercial configurable.
- Enlace a preguntas frecuentes.
- Acceso a WhatsApp únicamente si se configura un número real.

## FUNCIONALIDAD

Valida todos los campos y muestra estados accesibles.

No afirmes que el mensaje fue enviado si no existe backend o integración real.

En modo demostración, muestra una confirmación que indique claramente que el envío no está conectado.

No inventes dirección, teléfono, correo corporativo ni horarios de atención.

Crea una composición elegante y sencilla. Prioriza la facilidad de uso sobre la decoración.
