# PROMPT 12 — CONFIRMACIÓN DE PEDIDO

Desarrolla una página de confirmación para el flujo de checkout de demostración.

No presentes un pedido simulado como una compra real.

## ELEMENTOS

- Icono de confirmación accesible.
- Titular “Tu pedido de demostración está preparado”.
- Número de referencia generado durante la simulación.
- Resumen de productos.
- Total calculado.
- Aviso visible de que no se ha procesado ningún pago.
- CTA para volver al inicio.
- CTA para continuar explorando la tienda.

## COMPORTAMIENTO

Lee los datos de demostración desde un mecanismo local apropiado.

Si no existe un pedido válido, muestra una pantalla alternativa y ofrece volver al catálogo.

No muestres información personal innecesaria.

No generes números de pedido aleatorios cada vez que se recargue la página.

Implementa la página y prueba el flujo completo desde el carrito hasta la confirmación.
