# PROMPT 19 — PÁGINA 404 PREMIUM

Crea una página 404 visualmente elegante y coherente con ESSENCE & TIME.

Concepto: “Parece que esta esencia se ha perdido”.

Incluye:

- Mensaje claro.
- Ilustración o fotografía de producto elegante.
- Botón para regresar al inicio.
- Enlace a perfumes.
- Enlace a relojes.
- Buscador opcional.

No utilices una pantalla de error genérica.

La página debe ser ligera, responsive y accesible.

Comprueba que todas las CTA funcionen y que la página pueda utilizarse sin depender de JavaScript para mostrar su contenido esencial.
