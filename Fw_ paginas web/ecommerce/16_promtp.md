# PROMPT 15 — PREGUNTAS FRECUENTES

Desarrolla una página de FAQ para ESSENCE & TIME utilizando Bootstrap y componentes accesibles.

Organiza las preguntas por categorías:

- Pedidos.
- Productos.
- Envíos.
- Cambios y devoluciones.
- Pagos.
- Atención al cliente.

Implementa un buscador de preguntas frecuentes que filtre las preguntas visibles.

Utiliza acordeones con estados accesibles, navegación por teclado y una jerarquía visual clara.

No inventes políticas comerciales definitivas.

Cuando una respuesta dependa de información pendiente, utiliza textos configurables o marca el contenido como pendiente de validación antes de publicar.

Incluye enlaces a contacto, envíos y devoluciones.

Implementa y prueba búsqueda, apertura y cierre de acordeones.
