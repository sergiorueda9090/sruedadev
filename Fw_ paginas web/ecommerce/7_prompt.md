# PROMPT 06 — COLECCIÓN DE REGALOS

Crea una página editorial de regalos para ESSENCE & TIME.

El objetivo es ayudar a elegir perfumes, relojes y sets de regalo por estilo, presupuesto y ocasión.

## 1. HERO

Titular: “Regalos que dejan huella”.

Descripción: “Encuentra un detalle especial para celebrar momentos importantes.”

Utiliza fotografías de productos y empaques elegantes. No prometas envolturas especiales si no existen como servicio real.

## 2. ACCESOS POR OCASIÓN

Incluye:

- Cumpleaños.
- Aniversarios.
- Celebraciones.
- Detalles para sorprender.
- Regalos para él.
- Regalos para ella.

Estos accesos pueden funcionar como colecciones temáticas sobre el catálogo existente.

## 3. PRESUPUESTO

Crea filtros o accesos configurables por rango de precio en COP.

Los rangos deben ajustarse a los precios del catálogo.

## 4. SELECCIÓN DE PRODUCTOS

Muestra perfumes, relojes y sets disponibles.

No inventes combos, existencias ni descuentos. Si se crea un set conceptual, identifícalo como demostración.

## 5. DISEÑO

Utiliza una composición cálida y emocional, con fotografías editoriales, detalles discretos y suficiente espacio negativo.

## 6. FUNCIONALIDAD

Todos los accesos deben conducir a productos o colecciones filtradas.

Implementa los filtros y enlaces y verifica que los productos añadidos desde esta página aparezcan correctamente en el carrito.
